autoFocus is ignored on the root element of a new tree

Browsers focus an element with the autofocus attribute only when the attribute is already set as the element is inserted into the page. Inferno inserts the root element of each newly mounted tree into the page first and sets its props after that, so autoFocus on that element does nothing. Elements further down the new tree get their props while the tree is still detached, and they are focused.

A page processes autofocus only once, and not at all when something already has focus. Each case therefore runs on its own page load: open it with its link, and don't click in the page until the result appears.
